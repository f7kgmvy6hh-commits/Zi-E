# CAD
`ZI-E_Lite_v0.1_ASSEMBLY.step` is the nominal envelope model for packaging/visualization.
The manufacturing source of truth for hand-cut aluminum is the 1:1 PDF + DXF/SVG flat panels.
Because hand welding introduces fit-up and heat distortion, final seam trimming should be done on the actual shell rather than inferred from the STEP alone.

# Zi-E historical material

Everything below legacy/ is retained for provenance, recovery, or comparison. It
is not an active source of product, hardware, safety, pin-map, or commissioning
truth. Current engineering status lives in [docs/CURRENT_STATE.md](../docs/CURRENT_STATE.md).
These files remain available for history and idea recovery, but no artifact may be
copied into the active design without independent verification. See the
[legacy audit](../docs/LEGACY_AUDIT.md).

- exports/ contains packaged or migration-era repository presentations.
- snapshots/ contains repository snapshots such as Git bundles.
- Other pre-existing legacy references remain untrusted inputs under the rules in
  [AGENTS.md](../AGENTS.md).

No archive move reduces existing Git history. Any future history-size rewrite would
be a separate, explicitly approved destructive maintenance operation.
